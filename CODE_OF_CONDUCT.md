# Code of conduct

Be decent. Assume the other person is doing their best with incomplete
information, because in billing they almost always are.

Not welcome: harassment, personal attacks, or any of the usual reasons someone
stops contributing to a project.

Report a problem to **hello@billingdoctor.dev**. Reports are handled privately.
The maintainers may edit, delete or reject contributions, and may ban anyone
whose behaviour makes this a worse place to ask a question.

This is a short version of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies in full where this text is silent.
